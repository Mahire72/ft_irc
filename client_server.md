## Client 怎么连接 Server?
简单的网络系统：
                小明的电脑                         你的服务器电脑

                ┌─────────────┐                  ┌─────────────┐
                │ Chat Client │                  │ Chat Server │
                └──────┬──────┘                  └──────┬──────┘
                    │                                │
                    │────────── 网络 ────────────────│
                    │                                │
因此小明的程序通过IP address + Port 找到你的服务器。
